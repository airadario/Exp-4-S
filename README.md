# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:
To design and model a Hospital Management System using Unified Modeling Language (UML) by creating diagrams such as Use Case Diagram, Class Diagram, Activity Diagram, Sequence Diagram, and Package Diagram to represent the system's structure, behavior, and interactions efficiently.
# SRS (Procedure):
1. Identify the main actors of the Hospital Management System, such as Admin, Doctor, Patient, Nurse, Receptionist, and Pharmacist.

2. Define the main functionalities of the system, including patient registration, appointment booking, doctor management, billing, and medical record maintenance.

3. Draw the Use Case Diagram to represent the actors and their interactions with the hospital system.

4. Draw the Class Diagram to identify the classes, attributes, methods, and relationships between them.

5. Draw the Activity Diagram to represent the workflow of hospital activities, such as patient registration and appointment booking.

6. Draw the Sequence Diagram to show the sequence of interactions between actors and system objects during a particular operation.

7. Draw the Package Diagram to group related system components into packages such as Patient Management, Doctor Management, Appointment, Billing, and Medical Records.

8. Verify all UML diagrams to ensure that the system structure and workflows are properly represented.
